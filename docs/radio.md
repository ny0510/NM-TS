# 라디오 사용법

`/radio`에서 지역과 방송국을 선택합니다. 실제 FM 주파수가 확인된 채널은 FM 목록과 눈금에 표시하고, 인터넷 방송·AM·주파수 미확인 채널은 별도 목록에 둡니다. 지역별 주파수 출처는 [방송국 목록](radio-stations.md)에 있습니다.

좌우 버튼은 현재 주파수보다 낮거나 높은 다음 방송국으로 이동합니다. 끝에 도달하면 반대쪽 끝으로 이동합니다. 같은 주파수의 다른 송신소는 방송국 목록에서 선택할 수 있습니다. FM이 아닌 채널에서 좌우 버튼을 누르면 각각 가장 높은 / 낮은 FM 채널로 이동합니다.

음악과 라디오는 동시에 재생할 수 없습니다. 음악 재생 중 `/radio`를 사용하면 조작 화면을 열기 전에 전환 여부를 묻습니다. 요청한 사람이 같은 음성 채널에서 2분 안에 전환 버튼을 누르면 음악과 대기열을 종료하고 라디오 조작 화면을 엽니다. 방송국을 선택하면 재생을 시작합니다. 라디오에서 음악으로 전환할 때도 같은 확인 절차를 거칩니다. `전환 안 함`을 누르면 기존 재생을 유지하고 확인 메시지를 취소 안내로 바꿉니다.

튜너는 채널에 공개되며 같은 음성 채널의 사용자가 함께 조작할 수 있습니다. 지역은 15개로 나누며, 지역마다 FM 방송국은 하나의 드롭다운으로 표시합니다. 인터넷 방송·AM·주파수 미확인 채널은 기타 채널 목록에 표시합니다.

`/now`는 라디오 재생 중 튜너를 다시 엽니다. `/pause`, `/resume`, `/volume`, `/stop`은 두 모드 모두 지원합니다. 라디오에는 음악 대기열·자동 재생·즐겨찾기를 적용하지 않습니다. 버튼이 만료되면 `/radio`로 다시 열 수 있습니다. 모드 전환 확인·완료·취소 메시지는 공개되며 오류 안내는 요청한 사용자에게만 표시합니다.

새 방송국 연결에 실패하면 기존 방송을 유지합니다. 재생 중 방송 스트림 자체가 종료되거나 실패하면 라디오 전용 오류를 한 번 안내하고 연결을 정리합니다. 음악 대기열 종료 안내는 표시하지 않습니다.

추가 이모지 업로드 및 설정은 [assets/radio](../assets/radio/README.md)를 참고하세요.
