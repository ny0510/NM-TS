# 라디오 튜너 이모지

기존 Figma 원본의 색상과 128×128 크기를 유지했습니다. `progress_*` 6개는 이미 등록된 원본이며, `radio_*` 9개가 추가 업로드 대상입니다. PNG는 Discord에 바로 업로드할 수 있습니다.

| 이모지 이름 | 환경 변수 |
| --- | --- |
| radio_marker_filled_start | RADIO_MARKER_FILLED_START |
| radio_marker_filled_middle | RADIO_MARKER_FILLED_MIDDLE |
| radio_marker_filled_end | RADIO_MARKER_FILLED_END |
| radio_marker_unfilled_start | RADIO_MARKER_UNFILLED_START |
| radio_marker_unfilled_middle | RADIO_MARKER_UNFILLED_MIDDLE |
| radio_marker_unfilled_end | RADIO_MARKER_UNFILLED_END |
| radio_circle_end | RADIO_CIRCLE_END |
| radio_filled_end | RADIO_FILLED_END |
| radio_unfilled_start | RADIO_UNFILLED_START |

업로드 후 각 환경 변수에 `<:이모지이름:이모지ID>`를 넣으세요. 예: `RADIO_MARKER_FILLED_MIDDLE=<:radio_marker_filled_middle:123456789012345678>`.

추가 이모지가 없어도 기존 프로그래스바와 별도 점 눈금으로 작동합니다. 점은 해당 칸에 방송국이 있다는 뜻이며 가까운 주파수 여러 개가 겹칠 수 있습니다. 정확한 주파수는 방송국 이름 옆에 표시됩니다.
